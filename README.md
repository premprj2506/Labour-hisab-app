# 📋 મજૂરી ખાતાવહી (Daily Labour & Wage Calculator)

રોજિંદી મજૂરી, હાજરી અને ઉપાડનો હિસાબ રાખવા, બે તારીખ વચ્ચેનો હિસાબ ગણવા, સુંદર ગુજરાતી PDF પ્રિન્ટ કરવા અને સીધા માલિકને વોટ્સએપ પર મોકલવા માટેની વેબ / PWA એપ્લિકેશન.

---

## 🌟 મુખ્ય વિશેષતાઓ (Key Features)

1. **દૈનિક રોજી & કામ મુજબ મજૂરી (Variable Work Payment):**
   - **ફિક્સ રોજી:** પૂરી હાજરી, અડધી હાજરી, ગેરહાજર.
   - **કામ મુજબ / ઉચક મજૂરી:** મજૂર પોતાની રકમ જાતે નાખી શકે છે (દા.ત. સોફા ફ્રેમ ફિટિંગ, પ્લાસ્ટર કામ, વગેરે) અથવા નંગ x ભાવ ગણી શકે છે.
2. **ઉપાડ અને એડવાન્સ ટ્રેકિંગ (Advance Tracking):**
   - લીધેલ ઉપાડ આપમેળે મજૂરીમાંથી બાદ થઈને ચોખ્ખી બાકી રકમ બતાવે છે.
3. **બે તારીખ વચ્ચેનો હિસાબ (Date Range Filter):**
   - શરૂઆતની તારીખ અને અંતિમ તારીખ પસંદ કરીને કોઈપણ સમયગાળાનો હિસાબ ૧ સેકન્ડમાં જુઓ.
   - ઝડપી ફિલ્ટર: આ મહિનો, ગયા મહિનો, છેલ્લા ૧૫ દિવસ, છેલ્લા ૭ દિવસ.
4. **ગુજરાતી PDF સ્લિપ / બિલ પ્રિન્ટ:**
   - શુદ્ધ ગુજરાતી યુનિકોડ ફૉન્ટ્સ સાથે તૈયાર થતું હિસાબ પત્રક.
   - વિગતવાર દૈનિક ટેબલ, સમરી બોક્સ અને સહીની જગ્યા.
5. **વોટ્સએપ ડાયરેક્ટ શેરિંગ:**
   - ૧-ક્લિકમાં માલિકના વોટ્સએપ નંબર પર ગુજરાતી સમરી મેસેજ અને PDF શેરિંગ.
6. **૧૦૦% ફ્રી હોસ્ટિંગ (Free for 3-4 Persons):**
   - Vercel અથવા Netlify પર લાઇફટાઇમ મફત હોસ્ટિંગ.
   - મોબાઈલમાં "Add to Home Screen" કરવાથી નોર્મલ એપ જેવી જ ચાલે છે.

## 🚀 લોકલ રન કરવા માટે (Run Locally)

```bash
cd labour-hisab-app
npm run dev
```

બ્રાઉઝરમાં `http://localhost:5173` ખોલો.
